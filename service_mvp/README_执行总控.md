# 信息消化器服务型 MVP 执行总控

## 7 天目标

- 拿到 20 个感兴趣用户。
- 拿到 5 个试用用户。
- 拿到 1 个真实付费用户。

## 当前版本定位

英文 YouTube AI/技术视频 -> 中文 Markdown 学习笔记。

先卖结果，不卖系统。早期用户只需要发链接，你交付一份可以直接收藏到 Obsidian / Markdown 笔记库的中文学习笔记。

## 今日固定动作

1. 选 1 条海外 AI/技术视频。
2. 提取字幕并清洗成 `transcript.txt`。
3. 使用 `02_固定Prompt.md` 生成笔记。
4. 按 `03_交付模板.md` 整理成最终稿。
5. 用 `04_小红书发布模板.md` 发 1 篇内容。
6. 用 `tracking/market_metrics.csv` 记录数据。
7. 有评论/私信时，用 `05_私信销售话术.md` 转微信和收款。

## 是否开始做网站的判断线

同时满足以下条件，再做 Landing Page 或 Web MVP：

- 有 5 个以上有效私信。
- 至少 1 个用户真实付款。
- 用户不是只要一次摘要，而是明确表达“以后还想继续用”。

## 今日完成标准

- 不是写了多少代码。
- 不是页面有多漂亮。
- 是有没有新的真实反馈、微信联系人、试用请求或付款。
